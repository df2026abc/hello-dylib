## 透视（`twin_esp.mm` 第 20-22 行）

| 数值 | 当前值 | 含义 | 调大/调小效果 |
|---|---|---|---|
| `kHeadHeight` | `1.75f` | 头顶离脚底的高度（米） | 调大 → 框变高；调小 → 框变矮 |
| `kBoxRatio` | `0.42f` | 框宽 ÷ 框高 | 调大 → 框变宽；调小 → 框变窄 |

代码位置：

```cpp
static const CGFloat kHeadHeight = 1.75f;   // 世界单位(Y轴)
static const CGFloat kBoxRatio   = 0.42f;   // 宽 = 高 * 0.42
```

## 自瞄（`twin_aim.mm` 第 21-24 行）

| 数值 | 当前值 | 含义 | 手感 |
|---|---|---|---|
| `cfg_max_turn_deg` | `42.f` | 最大转速（度/秒） | 调大 → 转得快；调小 → 转得慢、更自然 |
| `cfg_reaction_ms` | `180` | 反应延迟（毫秒） | 调大 → 更迟钝；调小 → 更灵敏 |
| `cfg_jitter_deg` | `0.35f` | 抖动幅度（度） | 调大 → 更抖；调小 → 更稳 |
| `cfg_switch_cd` | `800` | 切换目标冷却（毫秒） | 调大 → 换目标慢；调小 → 换目标快 |

代码位置：

```cpp
static float cfg_max_turn_deg = 42.f;
static int   cfg_reaction_ms  = 180;
static float cfg_jitter_deg   = 0.35f;
static int   cfg_switch_cd    = 800;
```

**这组数值来自原版 `anti_ban.lua` 的拟人化门控参数**（42°/s、180ms、0.35° 过冲），不是随便填的。

## 敌人判定（`twin_esp.mm` 第 200-216 行）

不是数值，是逻辑，已按你的要求固定：

```
1. 跳过自己
2. 跳过死亡
3. 跳过非存活
4. 团队战：Team 不同 = 敌人
5. 混战/单挑：Team 为空或不同 = 敌人
```

代码位置：

```cpp
if (m_pc_is_death && bool_of(inv0(m_pc_is_death, pc))) continue;
if (m_player_alive && !bool_of(inv0(m_player_alive, player))) continue;
if (m_player_team) {
    Il2CppObject *tv = inv0(m_player_team, player);
    if (tv) {
        int32_t t = int_of(tv);
        if (g_team == INT32_MIN) { g_team = t; continue; }  // 第一个 = 自己
        if (t == g_team) continue;                          // 队友
    }
}
```
